# Mips-VHDL-Pipeline
Uma demonstração de como é um VHDL que simula o funcionamente de um Mips Pipeline em VHDL.
Este repositório contém a implementação de um processador MIPS de 5 estágios com Pipeline. Diferente da versão monociclo, este design permite que múltiplas instruções sejam processadas simultaneamente em diferentes estágios, aumentando significativamente o throughput do sistema
