# Mips-VHDL-Monociclo
Uma demonstração de como é um VHDL que simula o funcionamente de um Mips em VHDL.
Este projeto consiste na implementação de uma arquitetura MIPS de ciclo único (monociclo) utilizando a linguagem de descrição de hardware VHDL. O processador é capaz de executar um subconjunto das instruções da arquitetura MIPS, processando uma instrução completa a cada ciclo de clock.
